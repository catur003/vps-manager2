SSH Keys

Buat apa fitur ini?

Supaya kamu bisa login SSH langsung ke server ini dari laptop/PC-mu TANPA ketik password tiap kali (pakai key, bukan password). Ini BEDA dari deploy Git repo private (itu diatur di halaman Deploy Baru / Notifikasi, pakai GitHub Personal Access Token, bukan SSH key).

Cara pakai (3 langkah):
  1. Di laptop/PC-mu (bukan di server), generate keypair kalau belum punya:
    ssh-keygen -t ed25519 -C "laptop-saya"
  2. Lihat isi PUBLIC key-nya (yang file .pub, BUKAN yang tanpa .pub - itu private, jangan pernah dibagikan):
    cat ~/.ssh/id_ed25519.pub
  3. Copy-paste seluruh baris hasilnya (dimulai dari ssh-ed25519) ke kotak di bawah, klik "Tambah Key".

Setelah ditambah, login langsung tanpa password lewat: ssh deploy_user@<IP-server-ini>

GitHub Accounts (repo PRIVATE)

Repo publik gak butuh ini. Untuk repo private, tambah akun di sini (Personal Access Token, bukan password) - dipilih lewat dropdown "Akun GitHub" saat Deploy Baru.

Belum punya token? Buat di GitHub: Settings → Developer settings → Personal access tokens → Generate new token (scope minimal: repo).

Auto-Deploy Webhook (GitHub)

Secret global buat verifikasi signature webhook - aktivasi PER PROJECT tetap lewat tombol "Webhook" di halaman Deployments.

Isi Secret ini persis sama di GitHub repo (Settings → Webhooks → Add webhook, content type application/json, event: push). URL webhook per-project bisa dilihat lewat tombol "Webhook" di halaman Deployments.

Cloudflare Integration

API Token dipakai buat fitur "Purge Cache" & "Under Attack Mode" di halaman Domains / SSL. Buat token di Cloudflare dashboard → My Profile → API Tokens, scope: Zone → Cache Purge → Edit, Zone → Firewall Services → Edit.

Provider
