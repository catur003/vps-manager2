Memeriksa status setup

Tunggu sebentar, VPS Manager sedang memeriksa apakah administrator sudah tersedia.

Buat administrator pertama

Token berasal dari terminal instalasi. Kredensial ini hanya digunakan untuk login manusia ke web panel.

Token berlaku 24 jam dan hanya dapat digunakan sekali.
3-32 karakter: huruf, angka, titik, dash, atau underscore.
Minimal 12 karakter. Paste dan password manager tetap didukung.
Administrator berhasil dibuat. Kamu akan diarahkan ke halaman login.
Token hilang atau kedaluwarsa? Masuk SSH lalu jalankan vps-manager setup-token regenerate.

Setup belum tersedia

Masuk SSH lalu jalankan vps-manager setup-token regenerate.
